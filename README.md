## Installation

### 1. Clone the repository
```bash
git clone https://github.com/Sho1don/kde_dotfiles.git
cd ~/kde_dotfiles
```

### 2. Run the install script
The script will automatically check for `stow` and back up existing configs:
```bash
chmod +x install.sh
./install.sh
```

### 3. Apply the theme
1. Open **System Settings** -> **Colors & Themes** -> **Global Theme**.
2. Select and apply **'Kde Flotats'**.
